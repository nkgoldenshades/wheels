ERROR YOU'RE EXPERIENCING:
───────────────────────────────────────────────────────────────────────────────
"22P02: invalid input syntax for type uuid: POST_ID_HERE"

WHEN:
───────────────────────────────────────────────────────────────────────────────
Calling: SELECT * FROM secure_create_booking('post-id', 'user-id', ...)

WHY:
───────────────────────────────────────────────────────────────────────────────

Your database has TWO versions of the function:

  1. OLD UUID VERSION (Created first when you deployed)
     └─ Signature: secure_create_booking(UUID, TEXT, TEXT[], TEXT, NUMERIC, INTEGER)
     └─ This tries to cast 'post-id' STRING to UUID type
     └─ UUID cast fails → Error "invalid input syntax for type uuid"
     └─ Postgres NEVER reaches the TEXT version because UUID version failed first

  2. NEW TEXT VERSION (Created when you deployed corrected SQL)
     └─ Signature: secure_create_booking(TEXT, TEXT, TEXT, TEXT, NUMERIC, INTEGER)
     └─ Would work perfectly if called
     └─ But Postgres tries UUID version first, fails, returns error

WHY BOTH VERSIONS EXIST:
───────────────────────────────────────────────────────────────────────────────

Timeline of your deployments:

  1. First deployment:
     Ran: ALL_DATABASE_FUNCTIONS_COMPLETE.sql
     Result: UUID version created ✓
     └─ secure_create_booking(UUID, TEXT, TEXT[], ...) → UUID

  2. Second deployment:
     Ran: SECURE_FUNCTIONS_SCHEMA_CORRECTED.sql
     Result: TEXT version ADDED (not replaced)
     └─ secure_create_booking(TEXT, TEXT, TEXT, ...) → BIGINT
     └─ Old UUID version still exists!

WHY NOT REPLACED:
  └─ PostgreSQL's CREATE OR REPLACE only replaces IDENTICAL signatures
  └─ UUID(UUID, TEXT, TEXT[], ...) ≠ TEXT(TEXT, TEXT, TEXT, ...)
  └─ Different signature = new overload, not replacement
  └─ So: OLD stays, NEW added = 2 versions coexist

═══════════════════════════════════════════════════════════════════════════════

SOLUTION:
───────────────────────────────────────────────────────────────────────────────

DROP the UUID versions (all 5 functions have both):

  1. secure_create_booking(UUID, TEXT, TEXT[], TEXT, NUMERIC, INTEGER)
  2. secure_process_payment(UUID, NUMERIC, TEXT, TEXT)
  3. secure_generate_otp(UUID, INTEGER)
  4. secure_verify_otp(UUID, TEXT, TEXT)
  5. secure_process_refund(UUID, TEXT, TEXT, NUMERIC)

After dropping:

  Postgres has ONLY TEXT/BIGINT versions:

  ✓ secure_create_booking(TEXT, TEXT, TEXT, TEXT, NUMERIC, INTEGER) → BIGINT
  ✓ secure_process_payment(BIGINT, NUMERIC, TEXT, TEXT) → TABLE
  ✓ secure_generate_otp(BIGINT, INTEGER) → TABLE
  ✓ secure_verify_otp(BIGINT, TEXT, TEXT) → TABLE
