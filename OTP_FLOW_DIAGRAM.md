```
│                         BOOKING CREATION FLOW                        │
└─────────────────────────────────────────────────────────────────────┘

   ┌──────────────────────┐

          │ }
          ▼

   │                    SUPABASE BACKEND                          │
   │                                                              │
   │  ┌────────────────────────────────────────────────────┐    │
   │  │ TRIGGER: booking_otp_trigger                       │    │
   │  │ (BEFORE INSERT on bookings table)                  │    │
   │  └────────────────┬───────────────────────────────────┘    │
   │                   │                                         │
   │                   ▼                                         │
   │  ┌────────────────────────────────────────────────────┐    │
   │  │ FUNCTION: set_booking_otp()                        │    │
   │  │                                                     │    │
   │  │ IF NEW.otp_code IS NULL THEN                       │    │
   │  │   NEW.otp_code := generate_otp()                   │    │

   │  │                                                     │    │

          │

   ┌──────────────┐

   └──────┬───────┘

   ┌──────────────────────┐

          │   bookingId: 456,
          │   userId: "user-1",
          │   enteredOtp: "123456"
          │ )
          ▼
   ┌──────────────────────┐
   │ otp_service.dart     │
   └──────┬───────────────┘
          │ Calls Supabase RPC:
          │ verify_otp(
          │   p_booking_id: 456,
          │   p_profile_customer_id: "user-1",
          │   p_entered_otp: "123456"
          │ )
          ▼
   ┌─────────────────────────────────────────────────────────────┐
   │                    SUPABASE BACKEND                          │
   │                                                              │
   │  ┌────────────────────────────────────────────────────┐    │
   │  │ FUNCTION: verify_otp()                             │    │
   │  │                                                     │    │
   │  │ 1. SELECT booking FOR UPDATE (lock row)            │    │
   │  │                                                     │    │
   │  │ 2. Security Checks:                                │    │
   │  │    ✓ Booking exists?                               │    │
   │  │    ✓ User owns booking?                            │    │
   │  │    ✓ Already verified?                             │    │
   │  │    ✓ Locked (5+ attempts)?                         │    │
   │  │                                                     │    │
   │  │ 3. Compare OTP:                                    │    │
   │  │                                                     │    │
   │  │    IF otp_code != entered_otp THEN                 │    │
   │  │      ❌ WRONG OTP                                  │    │
   │  │      • Increment otp_attempts                      │    │
   │  │      • Lock if attempts >= 5                       │    │
   │  │      • RETURN 'wrong_otp'                          │    │
   │  │                                                     │    │
   │  │    ELSE                                             │    │
   │  │      ✅ CORRECT OTP                                │    │
   │  │      • Set otp_verified = TRUE                     │    │
   │  │      • Set otp_verified_at = NOW()                 │    │
   │  │      • RETURN 'success'                            │    │
   │  │                                                     │    │
   │  └────────────────┬───────────────────────────────────┘    │
   │                   │                                         │
   └───────────────────┼─────────────────────────────────────────┘
                       │
                       │ Returns: 'success' | 'wrong_otp' | 
                       │          'locked' | 'not_found' | etc.
                       ▼
   ┌──────────────────────┐
   │ otp_service.dart     │
   └──────┬───────────────┘
          │ Converts to enum:
          │ OtpVerificationResult.success
          ▼
   ┌──────────────────────┐
   │ Flutter App          │
   │ (Provider)           │
   └──────┬───────────────┘
          │
          │ if (result.isSuccess) {
          │   ✅ Show success message
          │   ✅ Complete booking
          │   ✅ Release payment from escrow
          │ }
          │
          │ else if (result.isWrongOtp) {
          │   ❌ Show error: "Wrong OTP"
          │   ❌ Allow retry
          │ }
          │
          │ else if (result.isLocked) {
          │   🔒 Show: "Too many attempts"
          │   🔒 Contact support
          │ }
          ▼
   ┌──────────────┐
   │ Booking      │
   │ Completed!   │
   └──────────────┘
```

## 🔐 Security Features

### 1. Attempt Tracking
```
Attempt 1: Wrong OTP → otp_attempts = 1
Attempt 2: Wrong OTP → otp_attempts = 2
Attempt 3: Wrong OTP → otp_attempts = 3
Attempt 4: Wrong OTP → otp_attempts = 4
Attempt 5: Wrong OTP → otp_attempts = 5, otp_locked = TRUE 🔒
Attempt 6: Correct OTP → REJECTED (locked) ❌
```

### 2. Ownership Check
```
User A creates booking → profile_customer_id = "user-a"
User B tries to verify → REJECTED (unauthorized) ❌
User A verifies → ALLOWED ✅
```

### 3. Already Verified
```
First verification: Success → otp_verified = TRUE ✅
Second verification: REJECTED (already_verified) ❌
```

### 4. Row Locking
```
Provider A starts verification → SELECT ... FOR UPDATE (locks row)
Provider B tries to verify same booking → WAITS
Provider A completes → Row unlocked
Provider B continues → Sees already_verified ❌
```

## 🎯 Return Values

| Return Value | Meaning | Action |
|--------------|---------|--------|
| `success` | ✅ OTP verified | Complete booking, release payment |
| `wrong_otp` | ❌ Incorrect OTP | Show error, allow retry |
| `locked` | 🔒 Too many attempts | Show locked message, contact support |
| `not_found` | ❓ Booking doesn't exist | Show error |
| `unauthorized` | 🚫 User doesn't own booking | Show error |
| `already_verified` | ✅ Already verified | Show success or info |

## 🚀 Quick Start

1. **Install Backend** (5 minutes):
   ```sql
   -- Run in Supabase SQL Editor:
   -- 1. INSTALL_OTP_TRIGGER_FINAL.sql
   -- 2. CREATE_OTP_VERIFICATION_FUNCTION.sql
   -- 3. TEST_OTP_COMPLETE.sql (to verify)
   ```

2. **Test in Flutter** (5 minutes):
   ```dart
   // Create booking
   final booking = await BookingRepository.instance.createBooking(
     slotId: "123",
     providerId: "provider-1",
     userId: "user-1",
     price: 150.00,
     postMode: PostMode.instant,
     serviceType: ServiceType.passenger,
   );
   
   print("OTP: ${booking?.otp}"); // Should print 6-digit OTP
   
   // Verify OTP
   final result = await OtpService().verifyOtp(
     bookingId: int.parse(booking!.id),
     userId: "user-1",
     enteredOtp: booking.otp!,
   );
   
   if (result.isSuccess) {
     print("✅ Booking verified!");
   }
   ```
