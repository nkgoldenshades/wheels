🆘 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

Problem: Payment Shows Success but Booking Not Updated
  → Check Razorpay dashboard to verify payment went through
  → Manually update booking if webhook failed
  → Contact Razorpay support if issue persists

Problem: Customer Says Payment Succeeded but No Receipt
  → Check Razorpay transactions
  → Manually resend confirmation email
  → Verify booking status in database

Problem: Payment Fails Repeatedly
  → Ask customer to try different payment method
  → Check Razorpay for declined reasons
  → Consider bank issue or card limit

Problem: Double Charge
  → Verify in Razorpay (might be duplicate attempt)
  → Process refund for extra charge immediately
  → Check code for duplicate API calls
