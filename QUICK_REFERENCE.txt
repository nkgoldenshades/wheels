CRITICAL SCHEMA FACTS (Always Use These):
───────────────────────────────────────────────────────────────────────────────

Posts:
  posts.id = TEXT (not UUID)
  Example: 'post_abc123'

Bookings:
  bookings.id = BIGINT GENERATED ALWAYS (auto-generated, never insert manually)
  bookings.profile_customer_id = TEXT (customer profile id)
  bookings.profile_provider_id = TEXT (provider profile id)
  bookings.seat_keys = TEXT (not TEXT[] array)
  bookings.refund_requested = BOOLEAN (not refund_locked)

COMMON ERRORS & FIXES:
───────────────────────────────────────────────────────────────────────────────

Error: "cannot insert into column 'id' of relation 'bookings'"
Fix:   This should not occur with the corrected version (id omitted from INSERT)

Error: "Unknown datatype: text" when calling function
Fix:   Make sure you deployed SECURE_FUNCTIONS_SCHEMA_CORRECTED.sql
      (not the old corrected version)

Error: "Function not found"
Fix:   1. Verify all 5 functions exist (run verification query)
      2. Restart your app
      3. Clear app cache if needed

Error: "Type mismatch: expected bigint, got text"
Fix:   The app converts booking id to int via int.parse() automatically
      (booking_repository.dart line 851)
